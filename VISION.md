Oligolia is a free, open-source, offline-first desktop bioinformatics platform -- "gene editing for everyone." It packages a PyQt6 GUI around an embedded FastAPI backend (Biopython-powered) so the whole app runs as a native installer (DMG/Windows installer/AppImage) with no Python install and no hosted service required. Public repo: github.com/moonsoup/oligolia, MIT licensed, currently at v0.5.2 with automated GitHub Releases per version tag.

Core capabilities are broad and genuinely built out: simultaneous search across 8 external databases (NCBI Gene, Ensembl, UniProt, KEGG, Reactome, gnomAD, STRING, PDB); CRISPR guide design for SpCas9/Cas9-HF/AsCas12a/LwaCas13a with Doench scoring; a full sequence editor (indel, reverse-complement, translate/transcribe, IUPAC motif search); pairwise (Needleman-Wunsch/Smith-Waterman) and MUSCLE multiple-sequence alignment; VCF variant viewing with ClinVar/gnomAD annotation; protein physicochemical analysis; PCR primer design and restriction mapping; pathway/interaction analysis via Reactome/KEGG/STRING; and a three-tier protein structure lookup (RCSB PDB, then AlphaFold DB, then ESMFold) with an optional separate 3D-viewer companion app kept out of the core binary to avoid bundling Chromium.

Current state: an actively shipping product, not a prototype. It has a real backend pytest suite (README badge reports 70 tests passing), a custom QA pipeline under .claude/qa that drives the live backend against real NCBI gene data and auto-files deduped GitHub issues, a defined release/versioning policy (patch/minor bump rules tied to what changed), a marketing/docs site, and recent work adding plasmid/circular DNA support, a cloning workflow builder, and per-vendor ordering credentials in Settings.

Near-term direction, per its own project instructions: continued feature work on the workflow builder and a lab/company integration pathway (a form for labs wanting to plug Oligolia into their own LIMS or ordering systems), plus routine patch releases as bugs are found via the QA pipeline.
